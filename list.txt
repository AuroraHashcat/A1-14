密评辅助系统网页前端功能清单表
核心模块	具体任务	功能名称	核心要求	关联标准条款（GM/T 0116-2021）
一、测评准备模块	1. 项目启动	新项目创建功能	支持录入委托测评协议书编号、被测单位 / 系统名称、系统规模、测评周期；支持组建测评项目组，分配成员角色（项目负责人 / 密评人员）及权限	5.2.1、5.3（表 1）
项目计划书生成与管理功能	内置模板（含项目概述、工作依据、技术思路、工作内容、项目组织），支持在线编辑、导出（PDF/Word）、水印（测评方名称）；仅项目负责人可审批	5.2.1、5.3（表 1）
2. 信息收集和分析	调查表格生成与解析功能	生成含系统基本信息、密码应用情况、软硬件部署、业务信息的表格，支持导出空白表、在线接收填写后的表格并自动解析数据；支持自定义补充字段	5.2.2、5.3（表 1）
技术资料上传与分类存储功能	支持上传系统总体描述文件、密码应用文件、等保定级报告等，按 “系统资料 / 密码资料 / 管理资料” 分类；生成文件清单（名称、大小、上传时间 / 人）	5.2.2、5.3（表 1）
调查结果分析功能	自动汇总表格数据，生成系统基本信息摘要、密码应用现状初步评估；支持手动补充分析结论，结果可关联至方案编制模块	5.2.2
3. 工具和表单准备	测评工具清单管理功能	内置模板，支持录入工具名称、型号、用途、校准状态 / 时间，标记 “符合国密要求” 的工具；支持导出、打印	5.2.3、5.3（表 1）
标准表单生成与签署功能	一键生成现场测评授权书、风险告知书等，含标准核心条款（如系统备份要求）；支持在线填写关键信息、电子签名（测评方 / 被测单位）、导出存储	5.2.3、5.3（表 1）
4. 输出文档管理	测评准备文档汇总管理功能	按 “项目计划书 / 调查表格 / 技术资料 / 工具清单 / 标准表单” 分类展示，支持查看、下载、版本管理（修改时间 / 人）；文档关联对应项目，不可跨项目访问	5.3（表 1）
二、方案编制模块	1. 测评对象确定	被测系统基本情况提取功能	导入测评准备阶段数据，自动提取物理环境、网络拓扑、核心资产、密码产品 / 服务等信息，生成系统基本情况清单	6.2.1、6.3（表 2）
系统描述编辑功能	以拓扑图为基础，按 “整体结构 - 边界连接 - 网络区域 - 业务功能” 总分式编辑，标注各部分密码应用情况；支持插入拓扑图截图	6.2.1
核心资产与威胁评估功能	支持选择核心资产类型（业务应用 / 数据 / 设备），设置资产价值等级（高 / 中 / 低）、威胁类型、威胁发生频率（高 / 中 / 低）；评估结果关联至测评对象确定结果	6.2.1
测评对象清单生成功能	自动生成含机房、软硬件、密码产品 / 服务、相关人员、管理制度的清单，记录所属区域、名称、用途、关联密码应用；支持编辑、导出	6.2.1、6.3（表 2）
2. 测评指标确定	基础测评指标自动关联功能	导入 / 选择系统定级结果，自动关联 GM/T 0115 对应等级指标，生成基础指标清单（编号、内容、适用性）	6.2.2、6.3（表 2）
特殊测评指标添加功能	支持根据行业标准 / 系统需求手动添加指标，录入内容、依据标准、适用场景	6.2.2
指标适用性核查功能	对不适用指标，需填写原因、替代性措施并上传证明；导入通过评估的密码应用方案，自动核查指标与方案一致性	6.2.2
测评指标确认清单生成功能	汇总基础 / 特殊指标、适用情况及原因，支持导出；作为测评检查点确定依据	6.2.2、6.3（表 2）
3. 测评检查点确定	关键设备检查清单生成功能	导入测评对象 / 指标清单，自动关联关键设备（承载核心资产 / 密钥管理），生成清单（设备名称、检查内容：算法合规性、配置符合性等）	6.2.3、6.3（表 2）
测评工具接入规划功能	支持上传拓扑图，标记接入点（边界 / 内部交换机），选择工具类型、测试目的 / 途径；生成规划图，支持导出、打印	6.2.3
测评检查点汇总表生成功能	汇总检查点名称、对应测评对象 / 指标、检查方法、风险控制措施（避开业务高峰期）；支持编辑、导出，作为现场测评依据	6.2.3、6.3（表 2）
4. 测评内容确定	单元测评实施表格生成功能	导入测评对象 / 指标 / 检查点数据，自动生成表格（指标编号、测评对象、内容描述、方法、预期结果）；支持按安全层面分类、编辑、导出为现场执行表	6.2.4、6.3（表 2）
5. 密评方案编制	密评方案模板生成功能	内置模板，导入委托协议 / 调查数据 / 各阶段结果，自动填充项目概述、测评依据、对象、指标、检查点、单元测评内容；支持编辑	6.2.5、6.3（表 2）
测评工作量估算功能	根据配置检查节点数、工具测试接入点 / 内容自动估算工作量；支持手动调整	6.2.5
密评方案评审与确认功能	支持发起内部评审（添加评审人、填写意见）；通过后导出给被测单位，提供确认入口，支持上传签字确认文档	6.2.5、6.3（表 2）
6. 输出文档管理	方案编制文档汇总管理功能	按 “测评对象 / 指标 / 检查点 / 单元测评 / 密评方案文本” 分类展示，支持查看、下载、版本对比；关联测评准备阶段数据，确保可追溯	6.3（表 2）
三、现场测评模块	1. 现场测评准备	首次会议管理功能	提供会议记录模板（时间、地点、参会人、测评工作介绍、计划 / 风险确认）；支持在线填写、电子签名、导出	7.2.1、7.3（表 3）
测评资源确认功能	录入被测单位配合人员信息、提供的测评条件；确认系统 / 数据已备份，上传备份证明	7.2.1
密评方案现场更新功能	支持调整方案（如检查点变更），填写更新原因；更新后需重新签字确认，生成更新记录（内容、时间、确认人）	7.2.1
授权书 / 风险告知书签署功能	在线展示文档全文，支持测评方 / 被测单位电子签名；签署后自动存储至文档管理模块	7.2.1、7.3（表 3）
2. 现场测评和结果记录	多类型测评记录填写功能	提供访谈 / 文档审查 / 实地察看 / 配置检查 / 工具测试记录模板，支持实时填写、上传佐证材料（录音 / 截图 / 抓包文件）；“符合情况” 仅可选（符合 / 不符合 / 部分符合 / 不适用），需填判定依据	7.2.2、7.3（表 3）
密码产品核验功能	录入认证证书编号，支持对接国密数据库核查有效性（暂不支持则人工核验）；核验结果记录至配置检查记录	7.2.2
测评记录实时保存功能	所有记录实时自动保存，防止数据丢失；支持按测评对象 / 指标筛选查看	7.2.2
3. 结果确认和资料归还	测评记录汇总与补充功能	自动汇总所有记录，按对象 / 指标筛选；支持标记遗漏内容，发起补充测评并记录补充时间 / 内容 / 结果	7.2.3
结束会议管理功能	提供会议记录模板（时间、参会人、结果沟通、争议问题处理）；支持在线填写、电子签名、导出	7.2.3
资料归还与环境恢复记录功能	提供归还记录模板（文档名称 / 数量、时间、接收人签字），上传归还凭证；记录现场环境恢复情况（工具移除、权限回收），需被测单位确认	7.2.3、7.3（表 3）
4. 输出文档管理	现场测评文档汇总管理功能	按 “会议记录 / 更新方案 / 授权书 / 测评记录 / 归还记录” 分类展示，支持查看、下载、按时间排序；关联方案编制阶段方案及指标，确保记录对应标准要求	7.3（表 3）
四、分析与报告编制模块	1. 单元测评	测评记录导入与关联功能	导入现场测评记录，自动关联 GM/T 0115 条款，按测评单元汇总各对象结果	8.2.1、8.3（表 4）
单元测评结果自动判定功能	按规则自动判定：所有对象符合→符合；均不符合→不符合；均不适用→不适用；其他→部分符合；支持手动调整（需填原因）	8.2.1
单元测评结果表生成功能	汇总测评单元名称、对象结果、单元结果、判定依据；支持导出，作为整体测评输入	8.2.1、8.3（表 4）
2. 整体测评	关联分析功能	导入单元测评结果，针对 “部分符合 / 不符合” 对象，选择关联单元 / 层面对象，分析关联关系、作用（弥补不足 / 影响其他项）	8.2.2、8.3（表 4）
单元测评结果修正表生成功能	标注修正后对象结果、修正原因（如补充加密措施）；支持编辑，需上传修正依据；按安全层面汇总修正结果，生成层面结果表	8.2.2、8.3（表 4）
3. 量化评估	多维度得分自动计算功能	按规则计算：对象得分（符合→满分 / 部分符合→比例分 / 不符合→0 分）→单元得分→层面得分→整体得分；权重可默认（国密要求）或自定义	8.2.3、8.3（表 4）
总体评价生成功能	自动生成有效保护措施、安全问题总结；支持手动补充评价内容，关联量化得分；支持导出	8.2.3、8.3（表 4）
4. 风险分析	安全问题与威胁关联功能	导入单元修正结果、资产威胁评估数据，自动提取 “部分符合 / 不符合项” 作为安全问题，关联威胁类型、频率、资产价值	8.2.4、8.3（表 4）
风险值自动计算与等级评价功能	按 “威胁利用可能性 + 影响程度” 自动算风险值（高 / 中 / 低）；结合系统等保等级，判断高风险项及中低风险叠加情况；生成风险分析报告（问题、风险值、影响）	8.2.4、8.3（表 4）
5. 评估结论形成	评估结论自动生成功能	导入整体得分、风险报告，按规则生成结论：符合（无问题，得分 100）、基本符合（无高风险，得分≥阈值）、不符合（高风险或得分＜阈值）；需负责人签字确认	8.2.5、8.3（表 4）
6. 密评报告编制	密评报告模板生成功能	内置模板，导入各阶段结果，自动填充 10 大模块（项目概述、被测系统情况、测评范围 / 方法、单元 / 整体测评、量化评估、风险分析、结论、评价、问题及建议、附件）；支持编辑	8.2.6、8.3（表 4）
密评报告评审与签发功能	发起内部评审（批注修改）；通过后由授权签字人在线签字；签发后导出（PDF，带签字 / 公章水印），支持上传被测单位接收确认文档	8.2.6、8.3（表 4）
7. 输出文档管理	分析报告文档汇总管理功能	按 “单元测评 / 整体测评 / 量化评估 / 风险分析 / 评估结论 / 密评报告文本” 分类展示，支持查看、下载、内容检索；关联现场测评记录，确保结果追溯至原始证据	8.3（表 4）
五、通用功能	1. 用户权限管理	多角色权限配置功能	支持项目负责人（审批）、密评人员（记录 / 编制）、被测单位人员（确认 / 查看）、系统管理员（用户 / 参数管理）角色；按角色控制功能 / 数据访问权限	4.1（客观公正性）
2. 数据安全	敏感信息脱敏与文档加密功能	敏感信息（密钥策略、核心数据）脱敏展示；上传文档加密存储；操作日志记录所有行为（人 / 时间 / 内容），不可删改	4.2（风险规避）、4.3（保密协议）
3. 易用性支持	流程引导与数据自动填充功能	各模块操作有引导提示（如 “需先导入调查数据”）；前期模块数据自动填充至后续模块，避免重复录入；提供帮助中心（操作指南、国密条款查询）	4.4（测评过程流畅性）
4. 兼容性支持	多浏览器适配与文档导出功能	支持 Chrome/Edge/Firefox；文档导出支持 PDF/Word，格式统一（字体、行距、表格对齐）；适配电脑端（分辨率≥1366×768）	通用标准要求
5. 进度追踪	项目进度看板功能
